High-Current Resistance Spot Welder

Power Electronics

Power electronics conversion system converting 18V / 10A input to a controlled 100A / 1V output for precision resistance spot welding.

Project Overview

Developed at Western University (Winter 2025). Resistance spot welding requires extremely high current at low voltage to generate localized Joule heating across metal interfaces. This project designed, simulated, and tested a modified buck converter topology paired with closed-loop PI current regulation.

Power Electronics & Control Design

  • Power Stage: Modified step-down buck converter designed for 15kHz switching frequency, utilizing Vishay SISS54DN MOSFETs (185.6A rating, 1.06mΩ Rds_on) and TI UCC27714 half-bridge gate drivers.
  • Signal Conditioning: Hall-effect current sensing coupled with precision op-amp conditioning (3.2x gain stage) feeding into microcontroller ADCs with anti-aliasing RC filtering.
  • Embedded Firmware: Arduino-based user interface (potentiometer + push button) with PI current regulation tuned via Ziegler-Nichols methods.
  • Validation: Comprehensive test plan covering pre-population continuity checks, MOSFET thermal testing, PWM isolation, and efficiency benchmarking (target ~88% efficiency).
