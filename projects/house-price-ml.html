House Price Prediction — Supervised ML Pipeline

Machine Learning

End-to-end regression pipeline built in Python, spanning robust data preprocessing, feature engineering, model training, and quantitative comparison.

Project Overview

A rigorous machine learning study evaluating various supervised regression models for real estate valuation, emphasizing statistical rigor, feature importance, and generalization.

Pipeline Architecture & Methodology

  • Data Preprocessing: Handled missing values, outlier removal, categorical encoding, and feature scaling using pandas and scikit-learn.
  • Feature Engineering: Developed domain-specific composite features (e.g., total square footage interactions, age-adjusted renovations, location clustering).
  • Model Evaluation: Trained and benchmarked multiple algorithms including Linear Regression, Random Forest Regressor, and Gradient Boosting.
  • Validation: Applied k-fold cross-validation and evaluated models using Root Mean Squared Error (RMSE) and R-squared metrics, supported by matplotlib feature-importance visualizations.
